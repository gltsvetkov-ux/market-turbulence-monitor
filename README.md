# Market Turbulence Monitor

Public research dashboard deployed to Render. ES/NQ snapshots are sourced from Yahoo Finance via yfinance using GitHub Actions (scheduled three times per weekday UTC; not exchange real-time). The snapshot reports 20/60-day realized volatility, historical percentile, and drawdown. These are descriptive measures, not forecasts or investment signals. Failed data refreshes do not overwrite the last valid snapshot. Inspect the timestamp on the dashboard.

The GitHub Actions workflow requires Actions to be enabled and workflow write permission. A first snapshot can be generated by manually running **Refresh MTM market snapshot** under GitHub Actions. This repository is public; never add secrets or account exports.

Credit Pulse is not integrated or accessed.
